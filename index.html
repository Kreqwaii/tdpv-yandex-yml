Маппинг полей 1С-Битрикс → YML (Яндекс Товары)

Соответствие свойств инфоблока каталога и торгового каталога элементам YML-стандарта.

Поле / Свойство 1С-Битрикс Тег / Атрибут YML Правило преобразования и валидации
ID <offer id="..."> Уникальный числовой идентификатор элемента инфоблока.
NAME <name> Очищенное название товара без HTML-тегов и лишних пробелов.
DETAIL_PAGE_URL <url> Абсолютный ЧПУ-URL карточки товара на домене https://tdpv.ru.
CATALOG_PRICE_1 <price>, <currencyId> Базовая цена в RUB. Если <= 0 или активно «Цена по запросу» — товар исключается.
IBLOCK_SECTION_ID <categoryId> Привязка к дереву разделов <categories>; неактивные разделы пропускаются.
DETAIL_PICTURE + MORE_PHOTO <picture> Абсолютные URL изображений (до 10 тегов на offer); без фото товар не выгружается или получает warning.
PREVIEW_TEXT / очищенный DETAIL_TEXT <description> HTML-теги удаляются, текст обрезается до лимита YML (до 3000 символов) в CDATA.
PROPERTY_MANUFACTURER <vendor> Наименование производителя / бренда (например, Ballu, Shuft, Ned, Systemair).
PROPERTY_CML2_ARTICLE <vendorCode> Заводской артикул из 1С; используется в отчётах контроля качества.
Свойства характеристик инфоблока <param name="..." unit="..."> Технические характеристики (мощность, расход воздуха, напряжение, уровень шума) с единицами измерения.

Атомарная генерация и расписание запуска

Защита от чтения битого или частично записанного XML-файла роботами Яндекса.

Атомарная запись файла

Генерация выполняется во временный файл yandex-tovary.xml.tmp через DOMDocument (UTF-8 без BOM), проверяется валидность структуры, после чего выполняется атомарный rename() в целевой yandex-tovary.xml.

Триггер и резервный cron

Основной запуск: автоматически по событию завершения 1С-обмена (OnSuccessCatalogImport1C) + резервный cron ежедневно в 04:15 МСК.
