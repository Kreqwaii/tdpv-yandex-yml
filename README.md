# Автовыгрузка Яндекс Товары (YML) + Отчёт контроля

Интерактивная демонстрация модуля выгрузки каталога 1С-Битрикс в формат Яндекс Товары (YML) с отчётом контроля исключённых позиций.

## Возможности
- **KPI-сводка**: количество включённых и исключённых товаров, статус генерации фида.
- **Переключение правил цены**: интерактивное управление флагом `toggle-price-req` с мгновенным пересчётом KPI.
- **Вкладки отчёта**: просмотр кейсов, исключённых позиций и итогового XML-фида.
- **Адаптивный интерфейс**: корректное отображение на десктопе и мобильных устройствах.
